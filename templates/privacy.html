Passport photo privacy

{{ cfg.SHOP_NAME }} processes your photo to produce the passport, visa or ID photo you select, and a passport photo code where supported.

  • The original shop photo is kept temporarily so staff can adjust the crop. It is deleted when a code is issued or the pending photo expires. Original public uploads are not retained.
  • Staff can print, save or email your photo. UK code retrieval requires an HM Passport Office signed request we verify.
  • Photos without a code are deleted after {{ cfg.PENDING_RETENTION_HOURS }} hours (the hourly cleanup may take up to one additional hour). Photos with a code expire after {{ cfg.RETENTION_DAYS }} days.
  • Your name and contact details are used only to send your code and are deleted with the photo.
