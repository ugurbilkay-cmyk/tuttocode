# Review preference

The user requested Claude review **on GitHub**, from now on. After pushing a
reviewable change to the active pull request, request `@claude review` and inspect
its findings when available. Keep this separate from local/mocked test results.
Report pending or unavailable review honestly; never imply Claude approved a
change merely because its bot acknowledged the request. Do not send customer
photos, DOBs, private job records or credentials in review comments or commits.

This development review preference does not change staff photo-code overrides
or introduce a new gate into the shop's operating workflow.
